# 001. Two Sum

- **链接**：https://leetcode.cn/problems/two-sum/
- **难度**：Easy
- **完成日期**：2026-09-20

## 思路

暴力做法是双层循环枚举所有数对，时间 O(n²)。

用哈希表换空间：一次遍历，把「已经见过的值 → 它的下标」记进表里。
走到 `nums[i]` 时，需要的另一半是 `target - nums[i]`，直接查表看它出现过没有。
出现过就同时拿到两个下标，答案是 `[之前的下标, i]`。

关键顺序：**先查再存**。如果先把当前元素存进去，`target` 恰好是 `2 * nums[i]` 时，
会拿同一个元素用两次，得到错误答案。

## 复杂度

- 时间：O(n)，每个元素只访问一次，哈希表查询是 O(1) 平均
- 空间：O(n)，最坏情况要把 n 个元素都存进表里

## 关键点

- 哈希表的 key 存**值**，value 存**下标**。这是能一次遍历出结果的原因。
- 不需要排序，所以不破坏原数组。题目要求返回下标，排序会打乱下标。
- 一旦找到就立即返回，不要继续遍历。

## 易错点 / 踩过的坑

- 一开始写成了先 `put` 再查，`[3, 3], target = 6` 这组用例过不了 —— 同一元素被算了两次。
- 用了 `HashSet` 然后想回头找下标，发现拿不到，只能用 `HashMap`。
- `int[]` 的返回写法是 `new int[] { a, b }`，不是 `new int[2]`（后者要两行赋值）。
